# Codex Usage

macOS 菜单栏用量工具。打开应用后，屏幕顶部会显示应用图标和当前固定服务的用量。点击图标即可查看 Codex、DeepSeek 和 GLM Coding Plan 的三张卡片。

## 账户配置

| 服务 | 如何连接 | 卡片显示 |
| --- | --- | --- |
| Codex | 在本机通过 `codex login` 登录 ChatGPT。应用会通过 Codex CLI 查询当前账户。 | 各周期的剩余百分比、恢复时间、可用 reset 次数和本机最近一次重置结果。 |
| DeepSeek | 点面板右下角齿轮，选择「DeepSeek 账户设置」，输入 API Key 并保存。 | 大字号显示可用总余额，下方列出充值余额和赠金。不同币种分别显示。 |
| GLM Coding Plan | 在「GLM 账户设置」中选择密钥所属的智谱国内站或 Z.ai 国际站，输入 API Key 并保存。 | 按账户返回的模型或积分周期显示剩余额度进度条。接口提供恢复时间时，同时显示倒计时。工具调用额度已隐藏。 |

DeepSeek 和 GLM 的密钥保存在本机 macOS 钥匙串中，可在对应账户设置中更换或移除。

## 菜单栏操作

- **展开与固定**：每次打开面板，三张卡片默认展开。点击标题可单独收起，点击图钉可把该服务移到顶部，并在菜单栏显示其用量。固定选择在重启后保留。
- **读进度条**：绿色是剩余额度，紫色是同一额度周期的剩余时间。倒计时期间，绿条比紫条短，表示当前额度消耗快于按时间均匀分配的速度。GLM 的 5 小时额度还未使用且没有恢复时间时，会显示满格紫条和「使用后开始计时」。将指针停在恢复倒计时上，可查看本地时区的完整时间，例如 `2026-11-19 09:04:07`。
- **刷新**：应用启动时查询一次，之后每 60 秒刷新。底栏刷新按钮可立即查询。某个服务查询失败时，对应卡片会显示原因；若有上次成功的数据，还会标明时间。
- **使用 reset**：Codex 卡片显示「使用 reset · 剩 N 次」时，点击会重新核对账户和次数，然后提交一次重置。卡片会记录本次操作的时间和结果。次数为零时显示「暂无可用 reset」；次数尚未取得时显示待查询。
- **退出**：点击右下角齿轮，选择「退出 Codex Usage」。

## 构建与安装

在装有 Swift 和 Xcode 命令行工具的 Mac 上，从项目根目录运行：

```sh
./build.sh
open "build/Codex Usage.app"
```

构建脚本会编译 Swift 源码、打包图标、检查 Info.plist，并完成本机临时签名和签名校验。要安装到「应用程序」，将生成的 `build/Codex Usage.app` 拖入该目录。更新已有安装时，先退出运行中的旧版，再替换并打开新版。

若 Codex 卡片无法读取用量，可在终端检查登录状态，并运行与卡片相同的只读查询：

```sh
codex login status
"build/Codex Usage.app/Contents/MacOS/CodexUsage" --check
```

`--check` 输出 Codex 用量周期数及可用 reset 次数，执行期间不会兑换 reset。
